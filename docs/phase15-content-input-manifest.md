## Поля по content contract (экскурсия)

- [ ] Настоящее название  
- [ ] Тип: auto / walking / custom  
- [ ] Подтверждённая цена или честное «от …»  
- [ ] Длительность  
- [ ] Размер группы  
- [ ] Кому подходит  
- [ ] Программа и ключевые точки (без выдуманных фактов)  
- [ ] Включено / не включено  
- [ ] Механика старта (без лишних приватных данных)  
- [ ] Условия заявки и ручного подтверждения  
- [ ] CTA с context attribution (`sourceType`, slug, title)  
- [ ] Реальные фотографии + право использования  
- [ ] SEO metadata  
- [ ] Owner approval
