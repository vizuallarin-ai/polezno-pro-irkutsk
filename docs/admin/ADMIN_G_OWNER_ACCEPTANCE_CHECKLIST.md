- [ ] Я открыл `/admin`
- [ ] Я вошёл под своим логином
- [ ] Я понимаю Главную
- [ ] Я вижу заявки
- [ ] Я могу открыть экскурсии
- [ ] Я могу открыть маршруты
- [ ] Я могу открыть статьи
- [ ] Я могу загрузить фото
- [ ] Я вижу Versions
- [ ] Я понимаю Restore
- [ ] Я могу пользоваться админкой с телефона
- [ ] Всё основное понятно без разработчика

После первого входа смените temporary password на свой сильный пароль (Account / штатный Payload flow, если доступен).

Технический login уже доказан Cursor. Этот checklist — **human acceptance**.
