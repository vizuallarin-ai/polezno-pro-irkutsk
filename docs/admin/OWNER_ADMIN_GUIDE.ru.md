# Руководство владельца — админка ИркПортала

Короткая операционная памятка после ADMIN.B–E. Не заменяет технический runbook.

## Вход

1. Откройте `/admin`.
2. Войдите email + пароль.
3. Роли: **Владелец** (основной доступ), **Контент-редактор** (только контент), **Разработчик** (техника).

Сброс пароля: попросите разработчика выполнить безопасный reset-скрипт на сервере (не публикуйте пароли в чатах).

## Главная

На главной `/admin` — обзор готовности, заявки (для владельца), черновики и быстрые действия. Редактор **не** видит блок заявок с персональными данными.

## Заявки (только Владелец / Разработчик)

1. Раздел **Заявки**.
2. Новые → возьмите в работу → назначьте следующий контакт.
3. Завершение: **Завершено** / **Отказ** / **Спам**.  
   **Не удаляйте** заявки — удаление отключено для владельца.

## Экскурсия

1. **Экскурсии** → Создать.
2. Заполните название; slug создаётся сам (можно поправить).
3. Сохраните черновик.
4. Для публикации нужны цена (или «по запросу»), длительность, описание.
5. Статус → **Опубликован**.

## Маршрут

1. **Маршруты** → Создать.
2. Точки и геометрия — по подсказкам в форме.
3. Черновик → проверка → **Опубликован**.

## Статьи

1. **Статьи**.
2. Управляйте полем **Статус публикации** (черновик / опубликован / скрыт / архив).
3. Не ориентируйтесь на технические кнопки Payload draft — статус синхронизируется автоматически.

## Фото и отзывы

Публикуйте через статус. Некачественные материалы сначала **Скрыт** или **В архиве**, не удаляйте сразу.

## Восстановление версии

Если ошибочно сохранили экскурсию/маршрут/статью/отзыв:

1. Откройте документ.
2. **Versions** (версии) → выберите прошлую → Restore.
3. Проверьте сайт/превью.

## Вместо удаления

| Ситуация | Действие |
|---|---|
| Убрать с сайта | Скрыт / снять с публикации |
| Больше не нужно | В архиве |
| Заявка закрыта | Завершено / Отказ / Спам |
| Файл медиа | Попросите разработчика |

## Роли — что нельзя

- Редактор: нет заявок, нет пользователей, нет system Places/Partners.
- Владелец: не назначает роль «Разработчик», не удаляет разработчика.
- Никто не удаляет последнего владельца/разработчика (защита от lockout).

## Если что-то сломалось

1. Не паникуйте и не удаляйте данные.
2. Проверьте, не черновик ли материал.
3. Попробуйте восстановить версию.
4. Напишите разработчику: что меняли, когда, URL страницы.
5. Авария БД/сервера → разработчик по `docs/ops/ADMIN_RECOVERY_RUNBOOK.md`.
